# BabyVoice

베이비타임 앱을 음성 명령으로 대신 조작해주는 개인용 접근성 자동화 앱입니다.

## 핵심 동작 방식 (원석님 확인 기준)
베이비타임은 홈 화면 아이콘을 탭하면 **그 즉시 기본값(마지막에 쓴 값 등)으로 자동 기록**됩니다.
값을 바꾸고 싶을 때만 방금 생긴 리스트 최상단 항목을 열어서 상세 수정 후 저장하면 됩니다.

그래서 BabyVoice도 두 가지 경로로 동작합니다:
- **값/옵션 지정 없는 명령** (예: "목욕", "기저귀") → 아이콘 한 번 탭으로 끝
- **값/옵션 지정 있는 명령** (예: "분유 120", "기저귀 대변") → 아이콘 탭(자동 기록) →
  방금 생긴 리스트 항목 열기 → 값/태그 수정 → 저장

리스트 최상단 항목은 고유 ID로 구분할 수 없어서, **현재 시각 텍스트("08:38 PM" 형식)**로
찾아서 클릭합니다. 분 단위가 막 바뀌는 순간에는 실패할 수 있지만, 재시도 로직이 있어
잠시 후 새로 계산된 시각으로 다시 시도합니다.

## 빌드 방법 (컴퓨터 있는 경우)
1. Android Studio (최신 버전) 설치
2. 이 폴더 전체를 "Open" → 기존 프로젝트로 열기
3. Gradle Sync 자동 진행 (인터넷 필요)
4. 실제 갤럭시 기기를 USB 디버깅으로 연결 후 Run

## 빌드 방법 (폰/태블릿만 있는 경우, 클라우드 빌드)
컴퓨터 없이 GitHub의 서버가 대신 컴파일하게 만들 수 있습니다. `.github/workflows/build.yml`을
이미 포함해뒀습니다. 아래 순서대로 하면 됩니다.

### 준비물
- GitHub 계정 (없으면 폰 브라우저에서 github.com 가입, 무료)
- Termux (갤럭시탭에 Claude Code 파이프라인용으로 이미 설치되어 있을 가능성 높음)

### 절차
1. Termux에서 git이 없다면 설치: `pkg install git -y`
2. github.com에서 새 저장소(Repository) 생성 (Private으로 만들어도 됩니다. 이름 예: BabyVoice)
3. Termux에서 이 프로젝트 폴더로 이동 후 GitHub에 올리기:
   ```
   cd BabyVoice
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/내계정/BabyVoice.git
   git push -u origin main
   ```
   (push할 때 아이디/비밀번호를 물어보면, 비밀번호 자리에는 GitHub
   Personal Access Token을 써야 합니다. github.com → Settings →
   Developer settings → Personal access tokens 에서 발급, "repo" 권한 체크)
4. push가 끝나면 GitHub 저장소 페이지 → **Actions** 탭으로 이동
   → "Build APK" 워크플로가 자동으로 실행되는 게 보임 (몇 분 소요)
5. 완료되면 그 실행 결과 페이지 하단 **Artifacts**에 `BabyVoice-debug-apk`가 생김
   → 폰 브라우저로 그걸 탭해서 다운로드 (zip으로 받아지며 안에 .apk 파일 있음)
6. 다운로드된 zip을 갤럭시 기본 "내 파일" 앱에서 풀면 `app-debug.apk`가 나옴
7. 그 apk 파일을 탭해서 설치 (최초 1회 "출처를 알 수 없는 앱 설치 허용" 필요 —
   설정에서 허용하라는 팝업이 뜨면 그대로 따라가면 됨)

이후로는 코드를 수정할 때마다 같은 방식으로 Termux에서 `git add . && git commit -m "수정" && git push`만
하면 GitHub가 자동으로 새 apk를 만들어줍니다. 컴퓨터도, Android Studio도 전혀 필요 없습니다.

## 확인 완료된 정보 (2026.08 기준)
- 패키지명: `yducky.application.babytime`
- 홈 화면 아이콘: 분유 / 이유식 / 기저귀 / 수면 / 목욕 / 병원 (스크롤하면 체온 / 투약 / 간식 / 우유 / 물 / 놀이 추가)
- 저장 버튼 텍스트: "저장" (모든 상세 화면 공통)
- 체온 포함 모든 숫자(ml/g/℃) 영역은 탭하면 키패드가 떠서 직접 입력 가능 (확인 완료)
- **병원 / 놀이는 지원하지 않음** (요청에 따라 코드에서 제외)

### 카테고리별 화면 구조
| 카테고리 | 숫자 입력 | 하위 태그/옵션 |
|---|---|---|
| 분유 | ml | - |
| 이유식 | ml/g | 소고기/미음/과일 |
| 간식 | ml/g | 우유/퓨레/아기치즈 |
| 우유 | ml | - |
| 물 | ml | - |
| 체온 | ℃ | 콧물/기침/구토/설사 (코드 미반영, 필요시 추가 가능) |
| 기저귀 | 없음 | 소변/대변/둘다 |
| 수면 | 없음 | 밤잠/낮잠 |
| 목욕 | 없음 | - |
| 투약 | 없음 | 해열제/항생제/지사제/기침약 |

## 명령 예시
| 음성 명령 | 동작 |
|---|---|
| "목욕" | 아이콘 탭만으로 즉시 기록 완료 |
| "기저귀" | 아이콘 탭만으로 즉시 기록 완료 (기본값 그대로) |
| "기저귀 대변" | 탭 → 방금 항목 열기 → 대변 선택 → 저장 |
| "분유 120" | 탭 → 방금 항목 열기 → 120ml 입력 → 저장 |
| "낮잠 잤어" | 탭 → 방금 항목 열기 → 낮잠 선택 → 저장 |
| "이유식 미음 50" | 탭 → 방금 항목 열기 → 미음 선택 → 50 입력 → 저장 |
| "투약 해열제" | 탭 → 방금 항목 열기 → 해열제 선택 → 저장 |

## 최초 설정
### 1. 권한 허용
앱 실행 후:
- 마이크 권한 허용
- "접근성 서비스 켜기" 버튼 클릭 → 설정 화면에서 BabyVoice(접근성 서비스) 켜기

## 사용법
1. 앱 실행 → "🎤 말하기" 클릭
2. 위 "명령 예시" 표의 문장으로 말하기
3. 자동으로 베이비타임 실행 → 아이콘 탭 → (필요시) 상세 화면 진입 → 값 입력 → 저장

## 테스트 방법 (실기기, 처음 한 번만)
1. Android Studio에서 USB로 연결된 갤럭시 기기에 앱 설치 (Run 버튼)
2. BabyVoice 앱 실행 → 마이크 권한 허용
3. "접근성 서비스 켜기" 버튼 클릭 → 설정 화면에서 **BabyVoice** 항목을 찾아 켜기
   (안드로이드가 "이 서비스는 화면의 내용을 볼 수 있습니다" 같은 경고를 보여주는데, 정상입니다)
4. BabyVoice 앱으로 돌아와서 "🎤 말하기" 클릭 → **"목욕"** 처럼 가장 간단한 명령부터 테스트
   (아이콘 탭 한 번으로 끝나는 명령이라 실패 지점이 가장 적음)
5. 성공하면 베이비타임 홈 리스트 최상단에 "목욕" 기록이 바로 보여야 함
6. 다음으로 **"분유 100"** 처럼 값이 있는 명령 테스트
   → 분유 아이콘 탭 → 리스트 최상단 항목 열림 → 100ml 입력 → 저장까지 확인
7. 마지막으로 **"기저귀 대변"**, "낮잠 잤어" 처럼 하위 태그가 있는 명령 테스트

### 실패 시 확인할 것
- `adb logcat -s BabyVoice` 로 로그 확인 (Android Studio 하단 Logcat 탭에서 "BabyVoice" 필터)
  - `단계 성공: ...` 로그가 안 보이고 `요소를 찾지 못해 포기` 만 반복되면, 해당 단계에서
    화면에 그 텍스트가 실제로 없거나 문구가 다른 것
- 특히 `ClickMostRecentEntry` 단계가 실패하면, 리스트 항목의 시각 표기 형식이
  "hh:mm a"(예: "08:38 PM")와 다를 수 있습니다. 베이비타임 화면에서 실제 표기를 캡처해서
  알려주시면 포맷을 맞춰드릴게요.
- 접근성 권한이 중간에 꺼져있진 않은지 (설정 > 접근성 > BabyVoice) 확인

## 남은 개선 여지 (선택)
- 체온의 콧물/기침/구토/설사 같은 증상 태그는 아직 코드에 반영 안 함 (필요하면 추가 가능)
- 상시 음성 대기(핫워드)는 미포함, 매번 마이크 버튼을 눌러 시작하는 방식
- "하이 빅스비"로 이 앱을 자동 실행시키려면, 갤럭시의 '모드 및 루틴' 앱에서
  "BabyVoice 앱 열기" 루틴을 만들고 빅스비로 그 루틴을 호출하면 됩니다
